# Web Intelligence & Data Extraction for Digital Marketing

This repository contains code modules, lab exercises, and practical scrapers developed as part of a structured Web Scraping curriculum focused on Digital Marketing Intelligence.

## Course Architecture
- **Module 1:** Protocols, HTTP Headers & DOM Inspection
- **Module 2:** Static HTML Extraction (`requests` + `BeautifulSoup`)
- **Module 3:** Dynamic Rendering & Browser Automation (`Playwright`)
- **Module 4:** Structured Data Pipelines (`pandas` + SQL)
- **Module 5:** Anti-Bot Evasion, Proxies & Scale

## Tech Stack
- **Language:** Python 3.x
- **Libraries:** `requests`, `beautifulsoup4`, `playwright`, `pandas`
- **Tooling:** Virtual Environments (`venv`), Git/GitHub
